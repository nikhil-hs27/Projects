# Neural Network Optimization

## Overview

The whole study focuses on using Neural Networks for classification.
Comparison is made on Neural Network with Convolutional layers amd without Convolutional layers. Further fine-tuning is done in terms of number of neurons, learning rate and choice of optimizers.

## Features

For the whole study, primary focus is to further develop on a model, by changing the parameters keeping the number of epochs constant.

Please go through the report for detailed explanation on the model architecture and interpretation of evaluation results.

## Usage

The best way to see the models in action is to clone the repository.

Be mindful, you might need install modules as per your environment. Best way to do this would be to run this in your terminal:
```Terminal
pip install <module>
```

Also, for quick execution, please decrease `epochs`. The current setting for `epochs` parameter is set to 10, which takes execution time per model to be 10-20 mins.
