# Text Classification and Chatbot Development

## Overview

In this era of information boom around the world and generative AI being the focus, mastering Natural Language Processing techniques is one of essential skills to have. 

The whole study is segmented to work on following six different tasks covering detailed implementation and evaluation:
- Eliza style chatbot to read regular expressions correctly
- A bigram language model (LLM) to attribute a particular string input to its most likely author
- Classifying Fake vs Real news article using Naive Bayes Classifier
- Implementing tf-idf vectorization for a given word from a text.
- Performing Sentiment Analysis, comparing Logistic Rregression and MLP Classifier
- Using POS-tagging for classification

## Features

For the whole study, primary focus is to build functions which can be used for similar other studies or compare results by changing parameters.

Please go through the Jupyter Notebook, as the logic used while implementing each task is explained along with individual task solutions

## Usage

The best way to see the functions in action is to clone the repository.

Be mindful, you might need install modules as per your environment. Best way to do this would be to run this in your terminal:
